# VELMORA — The Glass Tide Coast

A 1024x1024 travel poster for a fictional place: a twilight coast where the
sea glows glass-green, a giant natural rock arch frames a low amber moon, a
lit coastal town climbs the cliff with string lights, sailboats cross a
shimmering moonlight path, and a couple watches from a flower-lined terrace
with wine.

## Run

```sh
python3 main.py
```

Writes `/output/entry.png` (deterministic — the same bytes on every run).

## How it is drawn

Pure Pillow, no network, no external assets: layered gradients for the dusk
sky and the teal sea, a glowing moon with a shimmering reflection path, a
textured rock arch with strata and an amber rim light, a lit cliff town,
sailboats, a terrace couple, bougainvillea and lanterns, film grain and a
vignette. Fonts are the system Noto Serif Display and DejaVu faces.
